\chapter{More constructions}\label{chap:more-constructions}

In this chapter we discuss how a map $f\:\c{X}\to \c{Y}$ can be used to define a topology on $\c{Y}$ for a given topology on $\c{X}$.
This is very similar to the construction of the initial topology defined in Chapter~\ref{chap:constructions}, but
it essentially uses the notions of compactness and Hausdorffness that were discussed only later in the text.
