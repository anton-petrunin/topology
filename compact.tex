\chapter{Compactness}\label{chap:compactness}

In this chapter we define compact spaces --- especially nice topological spaces that behave in many ways like finite sets.


In practice, compactness is a powerful replacement for ``closed and bounded set'' in $\RR^n$, but the general definition does not resemble it at first glance.

\section{Definition}

We will denote by $\{V_\alpha\}=\{V_\alpha\}_{\alpha\in \c{I}}$ a family of sets, where $\alpha$ runs in an arbitrary index set $\c{I}$.

\begin{thm}{Definition}\label{def:cover}
A family $\{V_\alpha\}$ of open subsets of a topological space $\c{X}$ is called its \index{open cover}\emph{open cover} if it covers the whole $\c{X}$;
that is, if every $x\in \c{X}$ belongs to some~$V_\alpha$.

More generally, $\{V_\alpha\}$ is an \index{open cover}\emph{open cover} of a subset $S\subset \c{X}$ if any $s\in S$ belongs to some~$V_\alpha$.

A subfamily of the cover $\{V_\alpha\}$ that is also a cover is called its \index{subcover}\emph{subcover} of $\{V_\alpha\}$.
\end{thm}

Observe that any base of a space is a cover, but not every cover is its base.
For example, any space admits a cover by one set (the whole space), but it forms a base only for concrete spaces.

\begin{thm}{Exercise}\label{ex:open-open-cover}
Let $\{V_\alpha\}$ be an open cover of a topological space $\c{X}$.
Show that $W\subset \c{X}$ is open if and only if each intersection $W\cap V_\alpha$ is open.

Conclude that a map $f\:\c{X}\to \c{Y}$ is continuous if for any $\alpha$ the restriction $f|_{V_\alpha}\:V_\alpha\to\c{Y}$ is continuous.
\end{thm}

\begin{thm}{Definition}
A topological space $\c{X}$ is called \index{compact space}\emph{compact} if any cover $\{V_\alpha\}$ of $\c{X}$
contains a finite subcover $\{V_{\alpha_1},\z\dots,V_{\alpha_n}\}$.

Analogously, a subset $S$ of a topological space $\c{X}$ is called {}\emph{compact} if any cover of $S$
contains a finite subcover of $S$.
\end{thm}

Spelling the definitions, we get that \textit{a subset $S$ of a topological space is compact if and only if $S$ equipped with the induced topology is a compact space}.

Clearly, \textit{any finite topological space is compact}.
The next exercise provides a source of examples of infinite compact spaces.
More interesting examples are given in Section~\ref{sec:compact-interval} and further.

\begin{thm}{Exercise}\label{ex:cofinite-compact}
Show that any set equipped with the cofinite topology is compact.
\end{thm}

Let us show how one can apply the definition.

\begin{thm}{Observation}\label{obs:closed-bounded}
A compact subset $S$ of the real line has to be closed and \index{bounded set}\emph{bounded}; that is there is $c\in \RR$ such that $|s|\le c$ for any $s\in S$.
\end{thm}

\parit{Proof.}
Suppose $S\subset \RR$ is a compact set.
Assume $S$ is not closed.
Then we can choose a point $s\in\bar S\setminus S$ and consider the cover of $S$ by the complements of $[ s-\eps,s+\eps]$ for all $\eps>0$.
Since it has a finite subcover, a neighborhood of $s$ does not intersect $S$, so $s\notin\bar S$ --- a contradiction.

Applying the same reasoning for cover of $S$ by all intervals $(-c,c)$, one can show that $S$ is bounded.
\qeds

\section{Finite intersection property} 

\begin{thm}{Proposition}\label{prop:finite intersection property}
A topological space $\c{X}$ is compact if and only if for any family of closed sets $\{Q_\alpha\}$ in $\c{X}$ such that
\[\bigcap_{\alpha}Q_\alpha=\emptyset\]
there is a finite family $\{Q_{\alpha_1},\dots,Q_{\alpha_n}\}$
such that
\[Q_{\alpha_1}\cap\dots\cap Q_{\alpha_n}=\emptyset.\]

\end{thm}

We say that a family of sets has \index{finite intersection property}\emph{finite intersection property} if any finite subfamily of has non-empty intersection.
According to the proposition, compactness is equivalent to the following property: \textit{any family of closed sets with finite intersection property has a nonempty intersection}.

\parit{Proof.}
By the definition of closed sets, the complements $V_\alpha=\c{X}\setminus Q_\alpha$ are open.
Note that 
\[\bigcup_\alpha V_\alpha=\c{X}\setminus \left(\bigcap_{\alpha}Q_\alpha\right);\]
that is, $\{V_\alpha\}$ is an open cover of $\c{X}$ if and only if $\bigcap Q_\alpha=\emptyset$.


Observe that
\[Q_{\alpha_1}\cap\dots\cap Q_{\alpha_n}=\c{X}\setminus(V_{\alpha_1}\cup\dots\cup V_{\alpha_n}).
\]
Therefore, $\{V_{\alpha_1},\dots,V_{\alpha_n}\}$ is a finite subcover if and only if
the intersection $Q_{\alpha_1}\cap\dots\cap Q_{\alpha_n}$ is empty, hence the result.
\qeds

\end{thm}

\section{Real interval}\label{sec:compact-interval}

\begin{thm}{Theorem}\label{thm:comp-interval}
Any closed interval $[a,b]$ is a compact subset of $\RR$.
\end{thm}

\parit{Proof.}
Set $a_0=a$ and $b_0=b$, so $[a,b]=[a_0,b_0]$.

Arguing by contradiction, assume that there is an open cover $\{V_\alpha\}$ of $[a_0,b_0]$ that has no finite subcover.

Note that $\{V_\alpha\}$ is also a cover for two intervals 
\[[a_0,\tfrac{a_0+b_0}2]
\quad\text{and}\quad
[\tfrac{a_0+b_0}2,b_0].\]
Furthermore, if $\{V_\alpha\}$ has a finite subcover of each of these two subintervals,
then these two subcovers together give a finite cover of $[a_0,b_0]$.
Thus $\{V_\alpha\}$ must have no finite subcover for \textit{at least one} of these subintervals;
denote it by $[a_1,b_1]$;
so either $a_1=a_0$ and $b_1=\tfrac{a_0+b_0}2$ or $a_1=\tfrac{a_0+b_0}2$ and $b_1=b_0$.

Continuing in this manner we get a sequence of intervals 
\[[a_0,b_0]\supset [a_1,b_1]\supset\dots\] 
such that no
finite family of sets from $\{V_\alpha\}$ covers any of the intervals $[a_n,b_n]$.
In particular,
\[[a_n,b_n]\not\subset V_\alpha\quad\text{for any $n$ and $\alpha$.}
\eqlbl{[a,b]-not-in-V}\]

Observe that 
\[
a_0\le a_1\le \dots \le b_1\le b_0
\quad\text{and}\quad
b_n-a_n=\tfrac{b-a}{2^n}
\]
for any $n$.
Denote by $x$ the least upper bound of $\{a_n\}$.
Note that $x\in [a_n,b_n]$ for any $n$.%
\footnote{We also have that $a_n\to x$ and $b_n\to x$ as $n\to\infty$, but we will not use it.}

Since $\{V_\alpha\}$ is a cover, we can choose $V_\alpha\ni x$.
Since $V_\alpha$ is open, it contains an interval $(x-\eps,x+\eps)$ for some $\eps>0$.
Choose a large $n$ so that $\tfrac{b-a}{2^n}<\eps$.
Clearly, $V_\alpha\supset (x-\eps,x+\eps)\supset[a_n,b_n]$;
the latter contradicts~\ref{[a,b]-not-in-V}.\qeds



\section{Images}

\begin{thm}{Proposition}\label{prop:comp-image}
Let $f\:\c{X}\to\c{Y}$ be a continuous map between topological spaces, and let $K$ be a compact set in $\c{X}$.
Then the image $Q\z=f(K)$ is compact in $\c{Y}$.
\end{thm}

\parit{Proof.}
Choose an open cover $\{W_\alpha\}$ of $Q$.
Since $f$ is continuous, $V_\alpha=f^{-1}(W_\alpha)$ is open for each $\alpha$.
Note that $\{V_\alpha\}$ covers~$K$.

Since $K$ is compact, there is a finite subcover $\{V_{\alpha_1},\z\dots, V_{\alpha_n}\}$.
It remains to observe that $\{W_{\alpha_1},\dots, W_{\alpha_n}\}$ covers $Q$.
\qeds

\begin{thm}{Exercise}\label{ex:fun(compact)}
Let $f$ be a continuous real-valued function that is defined on a compact space $\c{K}$.

\begin{subthm}{ex:fun(compact):bounded}
Show that $f$ is \index{bounded set}\emph{bounded}; that is, there is a constant $c$ such that $|f(x)|\le c$ for any $x\in\c{K}$.
\end{subthm}

\begin{subthm}{ex:fun(compact):min-max}
Show that $f$ attains its maximum and minimum; that is, there are points $x_{\min},x_{\max}\in \c{K}$ such that
\[f(x_{\min})\le f(x)\le f(x_{\max})\]
for any $x\in \c{K}$.
\end{subthm}

\end{thm}

\section{Closed subsets}

\begin{thm}{Proposition}\label{prop:compact-closed}
A closed set in a compact space is compact.
\end{thm}

\parit{Proof.}
Let $Q$ be a closed set in a compact space $\c{K}$.
Since $Q$ is closed, its complement $W=\c{K}\setminus Q$ is open.

Consider an open cover $\{V_\alpha\}_{\alpha\in\c{I}}$ of $Q$.
Add to it $W$; that is, consider the family of sets that includes $W$ as well as $V_\alpha$ for all $\alpha\in\c{I}$.
Note that we get an open cover of $\c{K}$.
Indeed, $W$ covers all points in the complement of $Q$ and any point of $Q$ is covered by some~$V_\alpha$.

Since $\c{K}$ is compact, we can choose a finite subcover, say $\{W,V_{\alpha_1},\z\dots,V_{\alpha_n}\}$ --- without loss of generality, we can assume that it includes~$W$.
Observe that $\{V_{\alpha_1},\dots,V_{\alpha_n}\}$ is a cover of $Q$, hence the result.
\qeds

In the proof, we add an extra open set to the cover, use it, and take it away.
This type of reasoning is useful in all branches of mathematics;
sometimes it is called the \index{17 camels trick}\emph{17 camels trick}.%
\footnote{The name comes from the following mathematical parable~\cite{17-camels}:
\textit{A father left 17 camels to his three sons and, according to the will,
the eldest son should be given half of all camels,
the middle son the 1/3 part,
and the youngest son the 1/9.
It was impossible to follow his will until a wise man appeared.
He added his own camel, the oldest son took $18/2=9$ camels, the second son took $18/3=6$ camels, and the third son $18/9=2$ camels, the wise man took his camel and went away.}}


\begin{thm}{Exercise}\label{ex:closed-bounded=compact}
Show that any closed bounded subset of the real line is compact.
\end{thm}


\section{One-point compactification}

%??? change notation to $\dot{\c{X}}$ or so.

Choose a topological space $\c{X}$ and add to $\c{X}$ one extra point that will be denoted by $\infty$.
Let us define topology on $\c{X}^\infty=\c{X}\cup\{\infty\}$ such that
a set $V$ in $\c{X}^\infty$ is open if $V$ is an open subset in $\c{X}$ (in which case $\infty\notin V$) or $\infty\in V$ and its complement $\c{X}\setminus V$ is a closed \textit{and} compact subset of $\c{X}$.

To show that we have defined a topology, we need to check the conditions in \ref{def:top-space}:
\ref{SHORT.def:top-space:empty} is straightforward, \ref{SHORT.def:top-space:u} follows since intersection of closed and compact sets are closed and compact (see \ref{prop:compact-closed}), and \ref{SHORT.def:top-space:n} follows since union of two closed sets is closed and union of two compact sets is compact (see \ref{def:closed-properties:u} and \ref{ex:ucompact}).

Now, choose an open cover $\{V_\alpha\}$ of $\c{X}^\infty$.
Choose $\alpha_\infty$ such that $V_{\alpha_\infty}\ni\infty$.
By construction, the complement $K=\c{X}^\infty\setminus V_{\alpha_\infty}$ is compact.
Therefore we can choose a finite subcover $\{V_{\alpha_1}, \dots V_{\alpha_n}\}$ of $K$.
Observe that $\{V_{\alpha_\infty},V_{\alpha_1}, \dots V_{\alpha_n}\}$ covers $\c{X}^\infty$;
whence $\c{X}^\infty$ is compact.


The space $\c{X}^\infty$ constructed in the proof is called the \index{one-point compactification}\emph{one-point compactification} of $\c{X}$.
Observe that inclusion map $\c{X}\hookrightarrow\c{X}^\infty$ is an embedding.
Furthermore, if $\c{X}$ is not compact, then it is dense in $\c{X}^\infty$.
In particular, we proved the following statement.

\begin{thm}{Claim}
Every topological space is homeomorphic to a subspace of a compact space.
\end{thm}


\begin{thm}{Exercise}\label{ex:one-point-comp}
Show that one-point compactification of the real $\RR$ line is homeomorphic to the circle $\SS^1$.
\end{thm}

 
\section{Product spaces}

\begin{thm}{Theorem}\label{thm:compact-product}
Assume $\c{X}$ and $\c{Y}$ are compact topological spaces.
Then their product space $\c{X}\times\c{Y}$ is compact.
\end{thm}

The following exercise provides a partial converse.

\begin{thm}{Exercise}\label{ex:compact-product}
Suppose that a product space $\c{X}\times\c{Y}$ is nonempty and compact.
Show that its factors $\c{X}$ and $\c{Y}$ are compact.
\end{thm} 

In the proof, we will need the following definition.

\begin{thm}{Definition}
Let $\{V_\alpha\}$ and $\{W_\beta\}$ be two covers of a topological space $\c{X}$.
We say that $\{V_\alpha\}$ is \index{inscribed cover}\emph{inscribed}%
\footnote{One can also say that $\{V_\alpha\}$ \index{refinement}\emph{refines} $\{W_\beta\}$.}
in $\{W_\beta\}$ if for any $\alpha$ there is $\beta$ such that $V_\alpha\subset W_\beta$.
\end{thm}

\begin{thm}{Exercise}\label{ex:inscribed-cover-base}
Let $\s{B}$ be a base in a topological space $\c{X}$.
Show that for any cover $\{V_\alpha\}$ of $\c{X}$ there is an inscribed cover made from sets in~$\s{B}$.
\end{thm}

Suppose that $\{V_\alpha\}$ is inscribed in $\{W_\beta\}$.
If $\{V_\alpha\}$ has a finite subcover $\{V_{\alpha_1},\dots,V_{\alpha_n}\}$,
then for each $\alpha_i$ we can choose $\beta_i$ such that $V_{\alpha_i}\subset  W_{\beta_i}$.
Note that $\{W_{\beta_1},\dots,W_{\beta_n}\}$ is a finite subcover of $\{W_\beta\}$.
It proves the following:

\begin{thm}{Observation}\label{obs:inscribed-cover}
A space $\c{X}$ is compact if and only if any cover of $\c{X}$ has a finite inscribed cover. 
\end{thm}

It is instructive to solve the following exercise before reading the proof of \ref{thm:compact-product}.

\begin{thm}{Exercise}\label{ex:fake-proof(thm:compact-product)}
Find a flaw in the following argument.
\end{thm}

\parit{Fake proof of \ref{thm:compact-product}.}
Fix an open cover $\{O_\beta\}$ of $\c{X}\times\c{Y}$.
Consider all product sets $V_\alpha\times W_\alpha$ such that $V_\alpha\times W_\alpha\subset O_\beta$ for some $\beta$ (as before, $V_\alpha$ and $W_\alpha$ are open in $\c{X}$ and $\c{Y}$ respectively).
Note that $\{V_\alpha\times W_\alpha\}$ is a cover of $\c{X}\times\c{Y}$ that is inscribed in $\{O_\beta\}$.
By the observation, it is sufficient to find a finite subcover of $\{V_\alpha\times W_\alpha\}$.

Note that $\{V_\alpha\}$ is a cover of $\c{X}$.
Since $\c{X}$ is compact, we can choose its finite subcover $\{V_{\alpha_1},\dots,V_{\alpha_n}\}$.
Similarly, $\{W_\alpha\}$ is a cover of $\c{Y}$;
so we can choose its finite subcover $\{W_{\alpha_{n+1}},\dots,W_{\alpha_{n+m}}\}$.
It remains to observe that the products $V_{\alpha_i}\times W_{\alpha_i}$ for all $i$ cover $\c{X}\times\c{Y}$.
\qeds

Recall that by definition of the product topology, any open set in $\c{X}\times\c{Y}$ is a union of product sets
$V_\alpha\times W_\alpha$, where $V_\alpha$ is open in $\c{X}$ and $W_\alpha$ is open in $\c{Y}$.

Choose an open cover $\{O_\beta\}$ of $\c{X}\times\c{Y}$.
Consider all product sets $V_\alpha\times W_\alpha$ such that $V_\alpha\times W_\alpha\subset O_\beta$ for some $\beta$ (as before, $V_\alpha$ and $W_\alpha$ are open in $\c{X}$ and $\c{Y}$ respectively).
Note that $\{V_\alpha\times W_\alpha\}$ is a cover of $\c{X}\times\c{Y}$ that is inscribed in $\{O_\beta\}$.
By the observation, it is sufficient to find a finite subcover of $\{V_\alpha\times W_\alpha\}$.

Fix $x \in \c{X}$.
Note that the subspace $\{x\}\times \c{Y}$ is homeomorphic to $\c{Y}$; see \ref{ex:graph}.
In particular, the  set $\{x\}\times \c{Y}$ is compact.
Therefore, $\{x\}\times \c{Y}$ has a finite cover $\{V_{\alpha_1}\times W_{\alpha_1},\dots,V_{\alpha_n}\times W_{\alpha_n}\}$; that is,
\[(V_{\alpha_1}\times W_{\alpha_1})\cup\dots\cup
(V_{\alpha_n}\times W_{\alpha_n})
\supset \{x\}\times \c{Y}\]
Consider the set
\[N_x=V_{\alpha_1}\cap\dots\cap V_{\alpha_n};\]
note that $N_x$ is  open in $\c{X}$.
Since $N_x\subset V_{\alpha_i}$ for any $i$, we have
\[N_x\times \c{Y}\subset (V_{\alpha_1}\times W_{\alpha_1})\cup\dots\cup
(V_{\alpha_n}\times W_{\alpha_n}).\]
We get that
\begin{clm}{}\label{clm:Nx}
every point $x\in\c{X}$ admits an open neighborhood $N_x$ such that $N_x\times \c{Y}$ can be covered by finitely many product sets from $\{V_\alpha\times W_\alpha\}$.
\end{clm}


The sets $\{N_x\}_{x\in\c{X}}$ form a cover of $\c{X}$.
Since $\c{X}$ is compact, 
there is a finite subcover $\{N_{x_1},\dots,N_{x_m}\}$.
Note that 
\[\c{X}\times\c{Y}=(N_{x_1}\times \c{Y})\cup\dots\cup (N_{x_m}\times \c{Y});\]
that is, $\c{X}\times\c{Y}$ can be covered by a finite set of sets from $\{N_x\times \c{Y}\}_{x\in\c{X}}$.
Applying \ref{clm:Nx}, we get that $\c{X}\times\c{Y}$ can be covered by a finite number of product sets from $\{V_\alpha\times W_\alpha\}$.
\qeds

\section{Remarks}

We omit the proof of the following theorem, but it is worth knowing.

\begin{thm}{Alexander prebase theorem}
A topological space $\c{X}$ is compact if and only if for some (and therefore any) prebase $\s{P}$ in $\c{X}$, every cover of $\c{X}$ by elements of $\s{P}$ admits a finite subcover.
\end{thm}

Applying this theorem to the prebase from \ref{ex:graph:prebase} gives a short proof of \ref{thm:compact-product}.
Indeed, suppose that a cover of the product space $\c{X}\times \c{Y}$ consists only of products $V_\alpha\times  \c{Y}$ and $\c{X}\times W_\beta$, where $V_\alpha\subset \c{X}$ and $W_\beta\subset \c{Y}$ are open sets.
Note that that $\bigcup V_\alpha= \c{X}$ or $\bigcup W_\beta= \c{Y}$;
indeed, if there are $x\in \c{X}\setminus \bigcup V_\alpha$ and $y\in \c{Y}\setminus\bigcup W_\beta$, then $(x,y)$ is not covered by any $V_\alpha\times  \c{Y}$ or $\c{X}\times W_\beta$ --- a contradiction.
Without loss of generality, we can assume that $\{V_\alpha\}$ cover $\c{X}$.
Since $\c{X}$ is compact we can choose a finite subcover $\{V_{\alpha_1},\dots,V_{\alpha_n}\}$.
It remains to observe that $\{V_{\alpha_1}\times  \c{Y},\dots,V_{\alpha_n}\times  \c{Y}\}$ covers $\c{X}\times\c{Y}$ and apply the Alexander prebase theorem.

Let us show a more serious application of this theorem.

Start with a set $S$.
Denote by \index{Power}$\Power(S)$ the set of all subsets in $S$.
Given $s\in S$, define sets
\[\mathfrak{V}_s=\set{X\subset S}{X\ni s}
\quad\text{and}\quad
\mathfrak{W}_s=\set{X\subset S}{X\not\ni s}.
\]
Note that $X\subset S$ means that $X\in \Power(S)$, so $\mathfrak{V}_s,\mathfrak{W}_s\subset  \Power(S)$.

Let us equip the set $\Power(S)$ with topology defined by the prebase $\{\mathfrak{V}_s,\mathfrak{W}_s\}_{s\in S}$, now we can call it \index{power space}\emph{power space}.
Applying the argument above, one sees that \textit{$\Power(S)$ is a compact space for any set $S$}.
This is a partial case of the \index{Tychonoff compactness theorem}\emph{Tychonoff compactness theorem}.

For finite set $F$ the space $\Power(F)$ is a discrete space with $2^{|F|}$ points, which is compact --- not a surprise.

For the set of natural numbers $\NN=\{1,2,\dots\}$, a point $p\in \Power(\NN)$ is a subset $p\subset \NN$ and the map
\[p\mapsto 2\cdot \sum_{n\in p}3^{-n}\]
defines a homeomorphism from $\Power(\NN)$ to the Cantor set $\c{C}\subset [0,1]$; see \ref{sec:Cantor set}.

%Recall that the set $\c{C}$ constructed as an intersection of nested sequence of subsets $[0,1]\z=\c{C}_0\supset \c{C}_1\supset \dots$ such that $\c{C}_{i+1}$ is obtained from $\c{C}_i$ by deleting the open middle third from every line segment in it.

The following exercise describes a truly scary example of compact space.

\begin{thm}{Advanced exercise}\label{ex:power-power}
Let $\c{A}=\Power(\NN)$ and $\c{B}=\Power(\c{A})$; as we know $\c{B}$ is a compact space.
Show that the following sequence of points $\mathfrak{p}_1$, $\mathfrak{p}_2,\dots$ in $\c{B}$ does not have a converging subsequence:
\[\mathfrak{p}_n=\set{P\in\c{A}}{P\not\ni n}.\]

\end{thm}
