\section{Paths}\label{sec:Operations on paths}

A continuous map $f\:[0,1]\to \c{X}$ is called a \index{path}\emph{path}.
If $x=f(0)$ and $y=f(1)$ we say that $f$ is a path from $x$ to $y$.

Let us start with several examples and constructions of paths
\begin{itemize}
\item A path $f$ is called \emph{constant} if stays at one point.
In other words, $f(t)=p$ for some fixed point $p$; in this case, the path $f$ can be denoted by $\eps_p$.

\item Given a path $f\:[0,1]\to \c{X}$, one can consider the \index{time-reversed path}\emph{time-reversed} path $\bar f$, defined by
\[\bar f(t)=f(1-t).\]
Note that $\bar f$ is continuous since $f$ is.

\item Let $f$ and $h$ be paths in the topological space $\c{X}$.
If $f(1)=h(0)$ we can join these two paths into one $g\:[0,1]\to \c{X}$ that follows $f$ and then $h$;
so it is defined as
\[g(t)=
\left\{
\begin{aligned}
f(2\cdot t)&&\text{if}&\ t\le \tfrac12
\\
h(2\cdot t-1)&&\text{if}&\ t\ge \tfrac12
\end{aligned}
\right.
\]
The path $g$ is called the \index{product of paths}\emph{product} (or \index{concatenation}\emph{concatenation}) of paths $f$ and $h$; it is denoted as $g=f * h$.
Note that \ref{ex:u-continuous:closed} implies that $f*h$ is continuous;
in other words $f*h$ is indeed a path.
\end{itemize}

Consider the following relation on the set of points of a topological space:
\[x\sim y \quad\Leftrightarrow\quad\text{there is a path from $x$ to $y$.}\]

From above we have that $\sim$ is an equivalence relation on the set of points in $\c{X}$; in other words, the following properties hold for any points $x,y,z\in \c{X}$:
\begin{itemize}
 \item $x\sim x$ (since $\eps_x$ is a path from $x$ to $x$);
 \item if $x\sim y$, then $y\sim x$ (indeed, if $f$ is a path from $x$ to $y$, then $\bar f$ is a path from $y$ to $x$);
 \item if $x\sim y$ and $y\sim z$, then $x\sim z$ (indeed, if $f$ is a path from $x$ to $y$,
 and $h$ is a path from $y$ to $x$ then $f*h$ is a path from $x$ to $z$).
\end{itemize}

The equivalence class of a point $x$ for the equivalence relation $\sim$ is called the \index{path-connected component}\emph{path-connected component} of $x$;
this is the set of all point in $\c{X}$ that can be jointed with $y$ by a path.

\section{Path-connected spaces}

A space $\c{X}$ is called \index{path-connected space}\emph{path-connected} if it is nonempty and any two points in $\c{X}$ can be connected by a path;
that is, for any $x,y\in \c{X}$ there is a path $f$ from $x$ to $y$.
One can say that $\c{X}$ is path-connected if $\c{X}$ is a connected component of one (and therefore every) point $x\in\c{X}$.

\begin{thm}{Theorem}\label{thm:conncted/path-connected}
Any path-connected space is connected;
the converse does not hold.
\end{thm}

\parit{Proof; main part.}
Let $\c{X}$ be a path-connected space.

By Proposition~\ref{prop:connected[0,1]}, the unit interval $[0,1]$ is connected.
By Proposition~\ref{prop:image-connected}, for any path $f\:[0,1]\to \c{X}$ the image $f([0,1])$ is connected.

Fix $x\in \c{X}$.
Since $\c{X}$ is path-connected,
\[\c{X}=\bigcup_f f([0,1]),\]
where the union is taken for all paths $f$ starting from $x$.
It remains to apply~\ref{prop:union-connect}.

\parit{Second part.}
We need to present an example of a space that is connected, but not path-connected.

Denote by $I$ the closed line segment from $(0,0)$ to $(1,0)$ in $\RR^2$.
Further, denote by $J_n$ the closed line segment from $(\tfrac1n,0)$ to $(\tfrac1n,1)$.
Consider the union of all these segments
\[W=I\cup J_1\cup J_2 \cup \dots\]
and set 
\[W'=W\cup\{y\},\]
where $y=(0,1)$.
The space $W'$ is called the {}\emph{flea and comb};
the set $W$ is called the \index{comb}\emph{comb},
and the point $y$ is called the \index{flea}\emph{flea}.

\vskip-4mm
\includegraphics{mppics/pic-20}
\end{wrapfigure}

Note that $W\subset W'\subset \bar W$.
Therefore, by \ref{ex:A<B<bar-A}, $W'$ is connected.

It remains to show that $W'$ is not path-connected.
Assume the contrary. 
Let $f$ be a path from $x=(0,0)$ to $y=(0,1)$.

Note that $f^{-1}(\{y\})$ is closed subset of compact space $[0,1]$.
Therefore $f^{-1}(\{y\})$ is compact (\ref{prop:compact-closed}).
In particular, the set $f^{-1}(\{y\})$ has the minimal element,
denote it by $b$.
Note that $b>0$, $f(b)=y$ and $f(t)\ne y$ for any $t<b$.

Choose a positive $\eps<1$.
Since $f$ is continuous, there is $a<b$ such that $|f(t)-y|<\eps$ for any $t\in [a,b]$.
Note that $f(a)\in J_n$ for some $n$.

Denote by $N$ the intersection of the $\eps$-neighborhood of $y$ with the comb.
Note that the intersection of $J_n$ with $\eps$-neighborhood of $y$ forms a connected component of $N$.
By \ref{prop:image-connected}, $f(t)\in J_n$ for any $t\in [a,b]$;
in particular, $f(b)\ne y$ --- a contradiction.
\qeds

\begin{thm}{Advanced exercise}\label{ex:path-connected-component-closed-open:closed}
Consider the \emph{lexicographical order} $\prec$ on $\RR^2$:
\[
(x_1,y_1)\prec(x_2,y_2)
\quad\Leftrightarrow\quad
x_1<x_2\quad \text{or}\quad x_1=x_2\ \text{and}\  y_1<y_2.
\]
Show that the following sets for all pairs $(x_1,y_1)\prec(x_2,y_2)$ in $\RR^2$
\[I_{(x_1,y_1),(x_2,y_2)}\df\set{(x,y)\in \RR^2}{(x_1,y_1)\prec(x,y)\prec(x_2,y_2)}\]
form a base of some topology $\s{T}$ on $\RR^2$.

Furthermore, show that the squre $([0,1]\times[0,1]$ with the topology induced by $\s{T}$ is compact, Hausdorff, connected, but not path-connected, and each path-conencted component in $([0,1]\times[0,1],\s{T})$ is a veritcal interval $\{x\}\times[0,1]$.
\end{thm}

\section{Sets of Euclidean space}

The following theorem provides a class of topological spaces for which connectedness implies path-connectedness.

\begin{thm}{Theorem}\label{thm:open-connected=path-connected}
An open set in a Euclidean space $\RR^n$ is path-connected if and only if it is connected.
\end{thm}

\parit{Proof.}
The only-if part follows from \ref{thm:conncted/path-connected};
it remains to prove the if part.

Let $\Omega\subset\RR^n$ be an open subset.
Choose a point $p\in\Omega$; denote by $P\subset \Omega$ the path-connected component of $p$.

Let us show that for any point $q\in \Omega$ there is $\eps>0$ such that either $\Ball(q,\eps)\subset P$, or $\Ball(q,\eps)\cap P=\emptyset$.

Indeed, since $\Omega$ is open, we can choose $\eps>0$ such that the ball $\Ball(q,\eps)$ lies in $\Omega$.
Note that $\Ball(q,\eps)$ is convex, in particular path-connected.
Therefore $\Ball(q,\eps)\cap P\ne\emptyset$ if and only if $\Ball(q,\eps)\subset P$.

It follows that $P$ and its complement $\Omega\setminus P$ are open.
Since $\Omega$ is connected, we get that $\Omega\setminus P=\emptyset$ --- hence the result.
\qeds

A topological space $\c{X}$ is called \index{locally path-connected}\emph{locally path-connected} if for any point $p\in\c{X}$ and any open set $V\ni p$ there is a path-connected open set $W$ such that $V\supset W\ni p$.
For instance, Euclidean space is locally path-connected;
it follows since any open ball in a Euclidean space is path-connected.
Therefore the following exercise generalizes the theorem above.

\begin{thm}{Exercise}\label{ex:locally-path-connected}

\end{thm}

\end{thm}
