\chapter{Paths and homotopies}

Here we discuss paths and path-connected spaces,
We start with homotopy, which is more general than path.

\section{Homotopy}\label{sec:homotopy}

Two continuous maps $f,g\:\c{X}\to \c{Y}$ are called \index{homotopic}\emph{homotopic} (briefly, $f\sim g$) if $f$ can be continuously deformed into $g$ within the class of continuous maps.
Formally, this means that there exists a continuous map
\[
H\:\c{X}\times[0,1]\to \c{Y}
\]
such that $H(x,0)=f(x)$ and $H(x,1)=g(x)$ for all $x\in \c{X}$.
The map $H\:\c{X}\times[0,1]\to \c{Y}$ is called \emph{homotopy} from $f$ to $g$.

One should think of the homotopy $H$ is a one-parameter family of maps $h_t\:\c{X}\to \c{Y}$ defined by $h_t(x)=H(x,t)$.


\begin{thm}{Exercise}
Show that any two continous maps $\c{X}\to\RR^2$ are homotopic.
\end{thm}

\begin{thm}{Exercise}
Let $f_0, f_1\:\c{X}\to\c{Y}$ and $g_0,g_1\:\c{Y}\to \c{Z}$ be
four maps between topological spaces.
Assume that $f_0\sim f_1$ and $g_0\sim g_1$.
Show that $g_0\circ f_0\sim g_1\circ f_1$.
\end{thm}


\section{Operation on homotopies}\label{sec:homot-operations}

Observe that
\begin{itemize}
\item the \index{constant homotopy}\emph{constant homotopy} $H(x,t)=f(x)$ joins $f$ with itself;
\item if $H$ is a homotopy from $f$ with $g$, then the
\index{time-reversed}\emph{time-reversed} homotopy defined by
\[
\bar H(x,t)=H(x,1-t)
\]
is a homotopy from $g$ to $f$;
\item Consider two homotopies $H$ and $G$ from $f$ to $g$ and from $g$ to $h$, respectively.
Then their \index{concatenation of homotopies}\emph{concatenation} $F=H*G$ defined by
\[
F(x,t)=
\begin{cases}
H(x,2\cdot t),& t\le \tfrac12,\\
G(x,2\cdot t-1),& t\ge \tfrac12,
\end{cases}
\]
defines a homotopy from $f$ with $h$.
(By \ref{ex:closed-continuous}, $F$ is continuous.)
\end{itemize}

\section{Homotopy classes}

The previous section implies that $\sim$ is an equivalence relation on the set of continuous maps $\c{X}\to\c{Y}$; in other words, the following properties hold for any continuous maps $f,g,h\: \c{X}\to\c{Y}$:
\begin{itemize}
 \item $f\sim f$;
 \item if $f\sim g$, then $g\sim f$;
 \item if $f\sim g$, and $g\sim h$, then $f\sim h$.
\end{itemize}

The equivalence classes for $\sim$ are called \index{homotopy class}\emph{homotopy classes};
the equivalence class of a map $f\:\c{X}\to\c{Y}$ will be denoted by $[f]$.
Given two spaces $\c{X}$ and $\c{Y}$, the set of all homotopy classes will be denoted by
$\pi(\c{X},\c{Y})$.

Note that any homeomorphism $\c{Y}\to \c{Y}'$ defines a bijection between homotopy classes $\pi(\c{X},\c{Y})\to \pi(\c{X},\c{Y}')$ for any given space $\c{X}$.
So, stydying the homotopy classes may help to distiguish topological spaces.

Often the set $\pi(\c{X},\c{Y})$ admits a direct description; this is precisely its advantage over the vast set of all continuous maps $\c{X}\to \c{Y}$.

This construction is meaningful even for very simple choices of $\c{X}$.
If $\c{X}$ is the one-point space, then $\pi(\c{X},\c{Y})$ is also denoted by $\pi_0(\c{Y})$.
This is the main subject of this chapter.
Further we will do the case of circle, which is closely related to the fundamental group $\pi_1(\c{Y})$, which is the main subject of the following chapters.

This observation will guide us in the right direction.
However, the true motivation is different; it will described in Capter \ref{chap:algebra}.

\section{Paths}

A continuous map $f\:[0,1]\to \c{Y}$ is called a \index{path}\emph{path}.
If $x=f(0)$ and $y=f(1)$ we say that $f$ is a path from $x$ to $y$.

Note that path is a special case of homotopy with one-point sourse space $\c{X}$.
In particular we can talk about \index{constant path}\emph{constant paths} (path that stays at one point, say $p$; it will be denoted by $\eps_p(t)$) \index{time-reversed path}\emph{time-reversed path} and \index{concatenation of paths}\emph{concatenation of paths} defined in Section~\ref{sec:homot-operations}.
In this case the homotopy class corresponds to a subset of points in $\c{Y}$ which is called \index{path-connected component}\emph{path-connected component}.
Path-connected component of a point $y$, can be denoted by $[y]$; it is the set of all point in $\c{Y}$ that can be jointed with $y$ by a path.

\section{Path-connected spaces}

A space $\c{Y}$ is called \index{path-connected space}\emph{path-connected} if it is nonempty and any two points in $\c{Y}$ can be connected by a path;
that is, for any $x,y\in \c{Y}$ there is a path $f$ from $x$ to $y$.%
\footnote{One can say that $\c{Y}$ is path-connected if $[y]=\c{Y}$ for one (and therefore every) point $y\in\c{Y}$; here $[y]$ denotes the path-connected component of $y$.}

\end{thm}

\begin{thm}{Theorem}\label{thm:conncted/path-connected}
Any path-connected space is connected;
the converse does not hold.
\end{thm}

\parit{Proof; main part.}
Let $\c{Y}$ be a path-connected space.

By Proposition~\ref{prop:connected[0,1]}, the unit interval $[0,1]$ is connected.
By Proposition~\ref{prop:image-connected}, for any path $f\:[0,1]\to \c{Y}$ the image $f([0,1])$ is connected.

Fix $x\in \c{Y}$.
Since $\c{Y}$ is path-connected,
\[\c{Y}=\bigcup_f f([0,1]),\]
where the union is taken for all paths $f$ starting from $x$.
It remains to apply~\ref{prop:union-connect}.

\parit{Second part.}
We need to present an example of a space that is connected, but not path-connected.

Denote by $I$ the closed line segment from $(0,0)$ to $(1,0)$ in $\RR^2$.
Further, denote by $J_n$ the closed line segment from $(\tfrac1n,0)$ to $(\tfrac1n,1)$.
Consider the union of all these segments
\[W=I\cup J_1\cup J_2 \cup \dots\]
and set 
\[W'=W\cup\{y\},\]
where $y=(0,1)$.
The space $W'$ is called the {}\emph{flea and comb};
the set $W$ is called the \index{comb}\emph{comb},
and the point $y$ is called the \index{flea}\emph{flea}.

\begin{wrapfigure}{r}{33mm}
\vskip-4mm
\includegraphics{mppics/pic-20}
\end{wrapfigure}

Note that $W\subset W'\subset \bar W$.
Therefore, by \ref{ex:A<B<bar-A}, $W'$ is connected.

It remains to show that $W'$ is not path-connected.
Assume the contrary. 
Let $f$ be a path from $x=(0,0)$ to $y=(0,1)$.

Note that $f^{-1}(\{y\})$ is closed subset of compact space $[0,1]$.
Therefore $f^{-1}(\{y\})$ is compact (\ref{prop:compact-closed}).
In particular, the set $f^{-1}(\{y\})$ has the minimal element,
denote it by $b$.
Note that $b>0$, $f(b)=y$ and $f(t)\ne y$ for any $t<b$.

Choose a positive $\eps<1$.
Since $f$ is continuous, there is $a<b$ such that $|f(t)-y|<\eps$ for any $t\in [a,b]$.
Note that $f(a)\in J_n$ for some $n$.

Denote by $N$ the intersection of the $\eps$-neighborhood of $y$ with the comb.
Note that the intersection of $J_n$ with $\eps$-neighborhood of $y$ forms a connected component of $N$.
By \ref{prop:image-connected}, $f(t)\in J_n$ for any $t\in [a,b]$;
in particular, $f(b)\ne y$ --- a contradiction.
\qeds

\section{Open sets of Euclidean space}

The following theorem provides a class of topological spaces for which connectedness implies path-connectedness.

\begin{thm}{Theorem}\label{thm:open-connected=path-connected}
An open set in a Euclidean space $\RR^n$ is path-connected if and only if it is connected.
\end{thm}

\parit{Proof.}
The only-if part follows from \ref{thm:conncted/path-connected};
it remains to prove the if part.

Let $\Omega\subset\RR^n$ be an open subset.
Choose a point $p\in\Omega$; denote by $P\subset \Omega$ the path-connected component of $p$.

Let us show that for any point $q\in \Omega$ there is $\eps>0$ such that either $\Ball(q,\eps)\subset P$, or $\Ball(q,\eps)\cap P=\emptyset$.

Indeed, since $\Omega$ is open, we can choose $\eps>0$ such that the ball $\Ball(q,\eps)$ lies in $\Omega$.
Note that $\Ball(q,\eps)$ is convex, in particular path-connected.
Therefore $\Ball(q,\eps)\cap P\ne\emptyset$ if and only if $\Ball(q,\eps)\subset P$.

It follows that $P$ and its complement $\Omega\setminus P$ are open.
Since $\Omega$ is connected, we get that $\Omega\setminus P=\emptyset$ --- hence the result.
\qeds

A topological space $\c{Y}$ is called \index{locally path-connected}\emph{locally path-connected} if for any point $p\in\c{Y}$ and any open set $V\ni p$ there is a path-connected open set $W$ such that $V\supset W\ni p$.

Note that Euclidean space is locally path-connected;
it follows since any open ball in a Euclidean space is path-connected.
Therefore the following exercise generalizes the theorem above.

\begin{thm}{Exercise}\label{ex:locally-path-connected}
Show that an open set in a locally path-connected space is path-connected if and only if it is connected.
\end{thm}
